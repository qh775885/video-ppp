# 视频截图神器
一款基于 React + Electron 的现代化视频截图与自动提取工具。

## v2.0.1 新版特性 (React Refactor)
- **全新 UI 架构**：基于 React + Tailwind CSS 重构，带来丝滑的流畅体验。
- **智能区间提取**：
    - **拖拽选择**：直接在进度条上拖拽游标设定提取范围 (Start/End)。
    - **区间模式**：一键开启/关闭区间模式，专注提取精华片段。
- **高级参数控制**：
    - **倍数/张数联动**：调整提取倍数 (Density) 自动计算张数，或直接输入目标张数。
    - **实时反馈**：提取按钮实时显示选中区间的时长。
- **竖图模式 (Portrait)**：内置 9:16 裁剪预览，一键适配手机竖屏内容。
- **画廊系统**：集成 Lightbox 画廊，支持快捷键 (Esc) 关闭和键盘导航。

## 核心功能
1. **智能提取**：支持基于 SSIM/直方图的去重算法（保留核心逻辑），并引入倍数密度控制。
2. **极速预览**：基于 Electron + Chromium 内核，本地视频秒开，无缓冲。
3. **快捷键支持**：
    - `Space`：播放/暂停
    - `Starts / Ends`：拖拽手柄
    - `Esc`：关闭这是画廊**均分提取**：只需通过“⚡ 提取”输入目标张数（如 12 张），程序会自动根据视频时长计算间隔，均匀截取图片。
- **右键截图**：在视频任意位置点击鼠标右键（或按 `S` 键）即可通过当前裁切设置截图。

### 🖼️ 图库管理
- **双列网格**：侧边栏采用双列瀑布流布局，完整展示横/竖图，无裁切。
- **沉浸预览**：内置全屏 Lightbox，支持鼠标滚轮、键盘左右键、屏幕按钮流畅切图。

## 🛠️ 构建命令

为了方便版本管理，所有构建产物会自动输出到 `release/vX.X.X/` 目录下。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发模式
npm run dev

# 3. 构建免安装版 (Unpacked)
# 输出到 release/2.0.0/win-unpacked/，适合自己使用和调试
npm run build:local

# 4. 构建安装包 (Setup.exe)
# 输出到 release/2.0.0/，适合分发
npm run build:setup
```
