# 视频分图助手 (Video Frame Extractor)

一款简洁高效的视频自动分图工具，基于 Electron 构建。它可以帮助你快速从视频中提取清晰的关键帧图片。
![image](image.png) 

## ✨ 功能特性

- **🎬 拖拽加载**：直接将视频文件拖入软件即可快速加载预览。
- **🎯 智能分图**：
  - 支持自定义提取数量（1 - 300 张）。
  - 自动将视频分割为多个片段，尝试从每个片段中寻找最清晰的画面。
- **📂 本地缓存管理**：
  - 支持“设置本地缓存文件夹”。
  - 提取的图片会自动创建以视频文件名为名的子文件夹进行保存，方便整理。
- **🖼️ 现代化界面**：
  - 响应式侧边栏与网格布局。
  - 内置 Lightbox 图片查看器，支持大图浏览与切换。
- **🚀 极速体验**：优化了提取流程，提供流畅的操作反馈。

## 🛠️ 安装与运行

本项目基于 node.js 开发，请确保你的系统中已安装 Node.js。

### 1. 安装依赖

在项目根目录下运行终端命令：

```bash
npm install
```

### 2. 开发环境运行

启动 Vite 开发服务器并打开 Electron 窗口：

```bash
npm run electron:dev
```

### 3. 打包应用

构建 Windows 安装包（输出到 `release` 目录）：

```bash
npm run dist
```

## 🏗️ 技术栈

- **框架**: [Electron](https://www.electronjs.org/)
- **构建工具**: [Vite](https://vitejs.dev/)
- **语言**: JavaScript (ES6+), HTML5, CSS3
- **主要依赖**:
  - `electron-builder`: 打包构建
  - `file-saver`: 文件保存处理
  - `jszip`: 压缩包处理

## 📝 注意事项

- 默认最大提取帧数限制为 **300** 张。
- 视频处理速度取决于电脑配置及视频分辨率。
