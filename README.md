# 视频截图神器

一款简洁高效的视频帧提取工具，基于 Electron 构建。

## ✨ 功能

- **拖拽加载** - 直接拖入视频文件即可预览
- **智能提取** - 自动分析每个时间段，提取最清晰的画面
- **右键截图** - 拖动进度条到任意位置，右键即刻截取
- **数量可调** - 支持 1-300 张自定义提取数量
- **本地缓存** - 可设置缓存文件夹，自动按视频名创建子目录保存
- **图片浏览** - 内置 Lightbox 大图查看器，支持滚轮切换

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| `空格` | 播放/暂停 |
| `右键` | 截图 |
| `←` `→` | 快退/快进 5 秒 |

## 🛠️ 安装运行

```bash
# 安装依赖
npm install

# 开发模式
npm run electron:dev

# 构建测试版（不打包安装程序）
npm run electron:build

# 打包发布
npm run dist
```

## 📦 技术栈

Electron + Vite + JavaScript
