# 视频截图神器
一款基于 React + Electron 的视频截图与自动提取工具。



## 功能
- 拖入或点击导入视频，支持 MP4 / MKV / TS / AVI / MOV 等格式
- 逐帧快进快退，长按方向键或鼠标侧键匀速连跳
- 竖图裁切模式（9:16 等），可手动拖动或 AI 自动跟踪人物
- 批量智能提取，按倍率或目标张数均匀截取
- 截图自动保存到指定文件夹，侧边栏画廊预览
- 快捷键：`Space` 播放暂停、`S` / 右键截图、`I` / `O` 设置范围

## 构建

```bash
npm install
npm run dev    # 开发模式
npm run build  # 生产构建，输出到 release/
```
