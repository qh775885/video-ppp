# 视频截图神器

基于 React + Electron 的本地视频截图、优选与横转竖工具。

## 功能
- 导入本地视频，支持 MP4 / MKV / TS / AVI / MOV 等格式
- 逐帧快进快退，支持键盘和鼠标侧键长按连跳
- 竖图裁切，支持手动拖动裁剪框与右键直裁
- 按区间、倍率或目标张数批量提取
- 选择竖屏比例后，优选可直接输出竖图
- 截图自动保存到指定目录，并在侧栏预览
- 快捷键：`Space` 播放暂停，`S` / 右键截图，`I` / `O` 设置范围

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
# 目录绿色版，适合自己直接使用和归档保存
npm run build

# 安装版，适合面向普通用户发布
npm run build:setup
```
