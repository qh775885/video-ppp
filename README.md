# 视频截图神器 v2.0.0

一款基于 React + Electron 的现代化视频截图与自动提取工具。

## ✨ 核心特性

### 🎥 播放与控制
- **拖拽加载**：支持直接拖入文件或点击加载。
- **平滑快进**：进度条支持实时拖拽预览，键盘 `←` `→` 精确快进。
- **竖图模式**：专为短视频优化，支持 **9:16 遮罩裁切**，且裁切框可**左右拖动**以选择最佳构图。

### ⚡ 智能提取
- **均分提取**：只需通过“⚡ 提取”输入目标张数（如 12 张），程序会自动根据视频时长计算间隔，均匀截取图片。
- **右键截图**：在视频任意位置点击鼠标右键（或按 `S` 键）即可通过当前裁切设置截图。

### 🖼️ 图库管理
- **双列网格**：侧边栏采用双列瀑布流布局，完整展示横/竖图，无裁切。
- **沉浸预览**：内置全屏 Lightbox，支持鼠标滚轮、键盘左右键、屏幕按钮流畅切图。

## 🛠️ 构建命令

为了方便版本管理，所有构建产物会自动输出到 `release/vX.X.X/` 目录下。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发模式
npm run dev

# 3. 构建免安装版 (Unpacked)
# 输出到 release/2.0.0/win-unpacked/，适合自己使用和调试
npm run build:local

# 4. 构建安装包 (Setup.exe)
# 输出到 release/2.0.0/，适合分发
npm run build:setup
```

## 📦 技术栈
- **Core**: Electron 34
- **UI**: React 19 + Tailwind CSS v4
- **Build**: Electron Builder (NSIS)
