# 视频截图神器
一款基于 React + Electron 的现代化视频截图与自动提取工具。

## v2.0.8 新版特性 
- **骨灰级底噪 AI 大模型捕捉算法**：大幅升级了局部画面的跟踪过滤能力。不论是极度逼近的背影、腿部或是仅留片段残影（如只有臀部），只要能沾边，它就会敏锐地咬紧不放；配合全新的**惯性平滑演算**，彻底告别误判和画面撕裂漂移，指哪打哪。
- **顺滑级定频物理快进马达**：重构了播放机制，去除了之前依赖 DOM 阻断的长按延迟！现在只需按住 `长按方向键` 或带有原生连发的 `鼠标左右侧键` ，享受如水墨般丝滑的帧级别滑动快进退，极致沉浸。
- **全新高规格图标大换血**：挥别廉价图标，全版本升级到类似 macOS / Figma 最新高级扁平渐变水晶质感的高分辨率紫色 3D 桌面图标体系，不仅好用，而且很好看。
- **无限制格式支持**：不仅支持 MP4，还能秒开 TS 和 MKV，告别格式转换带来的烦恼。
- **极简极速操作**：HTML 层级拦截，实现零秒闪电启动无缝拖放，彻底拒绝界面冷加载白屏和“禁止拖入”红圈报错。

## 核心功能
1. **智能提取**：支持基于算法的重复度去除，可按倍数或目标张数，自动均分截取高质量图片片段。
2. **极速预览**：基于 Electron + Chromium 内核，超大视频秒开无缓冲。
3. **快捷交互**：
    - `Space`：播放 / 暂停
    - `S` 键 或是 `视频上点击右键`：提取当前画面
    - `⬅️ / ➡️`：丝滑逐帧倒退 / 快进
    - `Esc`：关闭画廊
4. **画廊系统**：侧边栏无裁切完整展示多比例（9:16 / 16:9 等）缩略图，双击进入全屏图库画廊。

## 🛠️ 构建命令

为了方便版本管理，所有构建产物会自动输出到 `release/vX.X.X/` 目录下。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发模式
npm run dev

# 3. 生产环境构建 (Build)
# 同时生成免安装版 (win-unpacked) 和安装包 (Setup.exe)
# 输出目录：release/vX.X.X/
npm run build
```
