# 协作偏好

> 最后更新：2026-04-22

## 总体偏好
- 默认优先小改、稳定、实用，不做低收益重构
- 不为了看起来高级而增加复杂度
- 修改要围绕用户当前问题，不顺手扩改无关区域

## UI 偏好
- UI 保持紧凑、便捷、少按钮
- 避免把界面越做越大、越做越空
- 横转竖以手动工作流优先，先保证顺手和直观

## 构建与发布偏好
- 改动后默认先运行 `npm run verify`
- 自用优先目录绿色版，便于按版本归档和回退
- 对外发布优先安装版
- 单文件绿色版当前不作为常用流程

## AI 方向偏好
- AI 功能在未明确推进前，先放着，不主动扩展
- 播放器控制栏内不保留 AI 锁定入口
- 如后续恢复 AI，优先考虑放在横转竖工作台中作为辅助能力
