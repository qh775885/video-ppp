# 当前重点

> 最后更新：2026-04-22

## 当前优先
- 优先稳定横转竖工作流，保持手动裁切顺手、紧凑、少按钮
- 默认构建使用目录绿色版，确保每个版本都能独立归档和回退
- 安装版只作为发布用产物，构建后不影响现有目录绿色版
- 改动后优先运行 `npm run verify`，不默认整包打包

## 当前暂缓
- 播放器控制栏内的 AI 锁定
- 横转竖里的 AI 自动框选人物
- 为低收益场景继续扩展复杂 AI 能力

## 已确认决策
- 自用优先目录绿色版；对外发布优先安装版
- 单文件绿色版当前不作为常用流程
- 选择竖屏比例后，优选直接输出竖图
- UI 继续保持紧凑、便捷，避免面板越做越大
