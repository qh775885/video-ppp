# 文档维护规则

## README.md
- **截图区域禁止改动**（`<img ... />` 这一段）
- 只简洁列出已实现功能，不写版本号、不写花哨描述
- 新增功能时在「功能」列表末尾追加一行
- 不删除、不重写已有条目，除非功能被移除
- 构建命令区域保持现状

## CHANGELOG.md
- 见 `versioning.md` 中的写作规范
- 新版本追加到文件顶部（`# 更新日志` 标题之后）

## 开发进度.md
- 记录当前版本的已完成事项和接下来要做的事
- 完成一个功能/修复后，及时从「接下来要做」移到「已完成」
- 保持「最后更新」日期为最新

## 迭代计划.md
- 宏观版本路线图，不记录细节
- 版本完成后将状态从 🔜 改为 ✅
- 不删除已完成的版本记录
